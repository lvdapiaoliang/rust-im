# 03 - 控制流与模式匹配

## 本章目标

掌握 `loop`/`while`/`for` 与 `match`/`if let`/`let else`。
模式匹配是 Rust 的「第一公民」，本篇是后面所有代码的地基。

## 一、循环三种

```rust
// loop：无限循环，但能带返回值（Java 没有的能力！）
let mut count = 0;
let result = loop {
    count += 1;
    if count == 10 { break count * 2; }   // break 带值
};

// while
let mut n = 3;
while n > 0 { n -= 1; }

// for：唯一常用的循环（【Java】for-each）
for i in 0..5 { print!("{i} "); }        // 0 1 2 3 4（右开区间）
for i in 0..=5 { print!("{i} "); }       // 0..5（右闭区间）
for c in "你好hi".chars() { print!("{c} "); }  // 按字符遍历（不是按字节！）
for b in "hi".bytes() { print!("{b} "); }      // 按字节遍历

// 带索引（【Java】for (int i=0; ...) 的替代）
for (i, v) in vec.iter().enumerate() {
    println!("{i}: {v}");
}

// 循环标签：从内层 break 外层
'outer: for x in 0..5 {
    for y in 0..5 {
        if x * y > 6 { break 'outer; }
    }
}
```

> 【实战】rust-im 的 echo server 读循环就是 `loop { read; write }`，
> 对端断开时 `return` 退出——`loop` 是网络编程里最自然的形态。

## 二、match：模式匹配完全体

```rust
enum Message {                     // 先认识 enum（下一篇详解）
    Quit,
    Move { x: i32, y: i32 },
    Write(String),
    ChangeColor(u8, u8, u8),
}

fn process(msg: Message) {
    match msg {
        Message::Quit => println!("退出"),
        Message::Move { x, y } => println!("移动到 ({x}, {y})"),   // 解构结构体字段
        Message::Write(text) => println!("写入: {text}"),          // 绑定内部值
        Message::ChangeColor(r, g, b) => println!("RGB({r},{g},{b})"),
    }
}
```

**match 的两条铁律**：

1. **必须穷尽**：漏一个分支编译不过（这是 Rust 比 Java switch 强大的根源——新增 enum 变体后，所有 match 处自动编译报错，重构安全）
2. **分支是表达式**：可以像三元一样当值用

```rust
let text = match code {
    200 => "OK",
    404 => "Not Found",
    500..=599 => "Server Error",   // 范围模式
    _ => "Unknown",                // _ 通配兜底（放在最后）
};
```

模式能力速查：

```rust
match value {
    0 => {},                       // 字面量
    1 | 2 => {},                   // 或
    3..=9 => {},                   // 范围
    n if n % 2 == 0 => {},         // 守卫（match guard）
    Some(x) if x > 100 => {},      // 守卫 + 解构
    ref r => {},                   // 借用而不 move
    other => {},                   // 绑定剩余值
}
```

## 三、Option 与 match 的天作之合

Rust **没有 null**。「可能没有值」用标准库的 `Option<T>` 表达：

```rust
enum Option<T> { Some(T), None }   // 标准库定义（无需 import）
```

> 【Java】`Optional<T>`（Java 8+）——但 Java 的 Optional 是「建议使用」，
> 任何引用仍可为 null；Rust 里**除了裸指针，类型系统里没有 null**，
> 编译器强制你处理 None。NPE 在 Rust 里不存在。

```rust
fn find_user(id: u64) -> Option<String> {
    if id == 1 { Some("alice".into()) } else { None }
}

let name = match find_user(1) {
    Some(n) => n,
    None => "匿名".to_string(),
};

// 常用组合子（不改数据只改包装）：
find_user(1).unwrap_or_default();        // None 时给默认值
find_user(1).unwrap_or_else(|| "匿名".into()); // 惰性默认
find_user(1).map(|n| n.to_uppercase());  // Some 时转换
find_user(1).ok_or("用户不存在")?;        // Option → Result（配合 ? 见下一篇）
find_user(1).and_then(|n| find_age(&n)); // 链式调用（flatMap）

// 千万不要随手 unwrap()（None 时 panic），那是测试和原型的用法
```

## 四、语法糖：if let / let else / while let

`match` 只关心一个分支时的简写：

```rust
// 完整 match
if let Some(name) = find_user(1) {
    println!("找到 {name}");
} else {
    println!("没找到");
}

// let else（Rust 1.65+）：提前退出的优雅写法
let Some(name) = find_user(1) else {
    return;                    // else 分支必须发散（return/break/panic）
};
println!("这之后 name 一定是 String，不再是 Option");   // 「卫语句」模式

// while let：循环取值直到 None（【实战】从 channel 循环收消息）
while let Some(msg) = rx.recv().await {
    println!("收到: {msg}");
}
```

> `let else` 是写 Rust 日常代码幸福感最高的语法之一：
> 它把 Java 里层层嵌套的 null 检查变成了平铺直叙的卫语句。
> 【实战】rust-im 客户端的消息循环就是 `while let Some(frame) = ...` 形态。

## 五、解构无处不在

```rust
// 解构结构体
struct Point { x: i32, y: i32 }
let Point { x, y } = Point { x: 1, y: 2 };
let Point { x, .. } = Point { x: 1, y: 2 };   // .. 忽略其余字段

// 解构嵌套
let (a, (b, c)) = (1, (2, 3));
let [first, .., last] = [1, 2, 3, 4, 5];       // 切片模式：1 和 5

// 解构在函数参数里也行
fn print_point(&(x, y): &(i32, i32)) { println!("{x},{y}") }
```

> 【Java】Java 21 的 record patterns 在追赶，但 Rust 从 1.0 起就是完备的，
> 且模式匹配和所有权/借用交织后（`ref`、`@` 绑定）表达力更强。
