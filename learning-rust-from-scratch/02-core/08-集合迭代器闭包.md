# 08 - 集合、迭代器与闭包

## 本章目标

掌握 Vec/HashMap 的所有权细节、迭代器适配器风格（函数式数据处理）、
闭包的三种捕获方式（Fn/FnMut/FnOnce）——Rust 日常代码的三大件。

## 一、Vec 与 HashMap 的所有权细节

```rust
let mut v = vec![3, 1, 4];
v.push(1);
v[0];                 // 越界 panic
v.get(10);            // Option<&T>，安全访问

let s = String::from("hi");
v.push(s.len() as i32);   // s 仍可用（len 返回 usize 是 Copy）

let owned: Vec<String> = vec!["a".into(), "b".into()];
// 【经典坑】遍历时修改：
// for x in &owned { owned.push(...); }   // ❌ 借用冲突
// 正确做法：先收集要加的，再 extend
```

```rust
use std::collections::HashMap;

let mut m: HashMap<String, u32> = HashMap::new();
m.insert("a".to_string(), 1);        // key/value 被 move 进 map！

let v = m.get("a");                  // Option<&u32>（借用）
let v = m.get("a").copied();         // Option<u32>
let v = m.get("a").copied().unwrap_or(0);

// 【实战高频】entry API：不存在则插入，存在则修改，一次查找搞定
*m.entry("hits".to_string()).or_insert(0) += 1;

// 遍历（顺序不确定！需要顺序用 BTreeMap）
for (k, val) in &m { println!("{k}={val}"); }
```

> 【Java】HashMap 用法接近，三大差异：
> ① key/value 是 move 进去的（Java 是引用）；
> ② entry API 比 `getOrDefault` + `put` 两步操作优雅且只哈希一次；
> ③ 没有 null，用 Option。需要有序遍历用 BTreeMap（红黑树，O(log n)）。

### 常用集合速记

| 集合 | 【Java】对应 | 特点 |
|------|--------------|------|
| `Vec<T>` | `ArrayList` | 连续内存，尾部 O(1) |
| `VecDeque<T>` | `ArrayDeque` | 双端队列，首尾 O(1) |
| `HashMap<K,V>` | `HashMap` | SipHash 抗碰撞攻击（DoS），可换 ahash 提速 |
| `BTreeMap<K,V>` | `TreeMap` | 有序，范围查询 |
| `HashSet`/`BTreeSet` | `HashSet`/`TreeSet` | 去重 |
| `BinaryHeap<T>` | `PriorityQueue` | **默认大顶堆**（取 min 要 `Reverse`） |

```rust
use std::cmp::Reverse;
use std::collections::BinaryHeap;
let mut min_heap: BinaryHeap<Reverse<u32>> = BinaryHeap::new();
min_heap.push(Reverse(3));
let Reverse(min) = min_heap.pop().unwrap();   // 3——最小值！
```

## 二、迭代器：惰性适配器链

```rust
let v = vec![1, 2, 3, 4, 5];

// 迭代器是惰性的：不消费就不执行
let iter = v.iter().map(|x| x * 2);       // 现在什么都没发生
let doubled: Vec<i32> = iter.collect();    // 消费时才计算

// 适配器链（【Java】Stream API 的零开销版）
let evens_sq: Vec<i32> = v.iter()
    .filter(|&&x| x % 2 == 0)
    .map(|x| x * x)
    .collect();

let sum: i32 = v.iter().sum();
let max: Option<&i32> = v.iter().max();
let (evens, odds): (Vec<_>, Vec<_>) = v.into_iter().partition(|x| x % 2 == 0);
let first_big = v.iter().find(|&&x| x > 3);        // Option，短路
let any = v.iter().any(|&x| x > 4);                 // 短路
let grouped = v.iter().fold(0, |acc, x| acc + x);   // 【Java】reduce

// 拼接、zip、chain、enumerate、take/skip、flat_map、zip …
let names = ["alice", "bob"];
let scores = [90, 85];
let pairs: Vec<(&str, i32)> = names.iter().zip(scores).collect();
```

### 三种迭代：iter / iter_mut / into_iter

```rust
let v = vec![String::from("a"), String::from("b")];
for x in &v { ... }        // iter()：&T，借用（最常用）
for x in &mut v { ... }    // iter_mut()：&mut T，可变借用
for x in v { ... }         // into_iter()：T，消费所有权！之后 v 不能用
```

> 记法：`for x in &v` / `for x in v` 一个 `&` 的差别决定 v 的存亡——
> 这是所有权系统最日常的体现。

### 为什么零开销

适配器链在编译期单态化成一层循环，等价手写 for（LLVM 常能消除边界检查）。
> 【Java】Stream 是运行时对象链，有装箱/虚调用成本（优化过的 IntStream 除外）。

### 手写迭代器

```rust
struct Counter { count: u32 }

impl Iterator for Counter {
    type Item = u32;
    fn next(&mut self) -> Option<u32> {
        self.count += 1;
        (self.count <= 5).then_some(self.count)
    }
}
// 直接获得 map/filter/collect/sum 全家桶（默认方法基于 next 实现）
let sum: u32 = Counter { count: 0 }.filter(|x| x % 2 == 0).sum();   // 6
```

> 【实战】rust-im 的去重窗口、定时轮都会实现自定义 Iterator——
> 实现 `next` 一个方法，白拿几十个组合子，这是 Rust API 设计的复利。

## 三、闭包

```rust
let factor = 3;
let mul = |x| x * factor;        // 捕获 factor（不可变借用）
assert_eq!(mul(4), 12);
// factor 在闭包存活期间仍可读（闭包只是借用了它）

let mut count = 0;
let mut inc = || count += 1;     // 捕获 &mut count
inc(); inc();
// count 被 &mut 借用中，inc drop 前不能再借用 count

let s = String::from("data");
let consume = move || drop(s);   // move：强制拿所有权（跨线程/spawn 必备）
```

三种 trait（按捕获能力从弱到强）：

| trait | 能做什么 | 闭包可调用次数 | 【Java】 |
|-------|----------|----------------|-----------|
| `Fn` | 只读捕获 | 多次 | 无副作用 lambda |
| `FnMut` | 可变捕获 `&mut` | 多次（需要 mut 闭包） | 有状态 lambda |
| `FnOnce` | 消费捕获（move out） | 一次 | 消费资源后即废 |

继承关系：`Fn: FnMut: FnOnce`（能力越弱，能实现的场景越多）。

函数参数怎么写：

```rust
fn apply<F: Fn(u32) -> u32>(f: F, x: u32) -> u32 { f(x) }
fn apply_mut<F: FnMut(u32) -> u32>(mut f: F, x: u32) -> u32 { f(x) }
fn apply_once<F: FnOnce() -> String>(f: F) -> String { f() }
// 高阶返回闭包：必须装 Box（或 impl Trait）
fn make_adder(n: i32) -> impl Fn(i32) -> i32 { move |x| x + n }
```

> 【Java】闭包捕获差异是重点：Java lambda 只能捕获 effectively final
> （不能改局部变量，只能改字段）；Rust 闭包能 `&mut` 捕获、能 `move` 拿走所有权，
> 全部由借用检查器保证安全。
