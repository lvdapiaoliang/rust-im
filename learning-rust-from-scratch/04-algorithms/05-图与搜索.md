## 一、图的表示

```
无向图示例：
    0 ── 1
    │    │
    2 ── 3
```

```rust
/// 邻接表：图的 Rust 标准表示（HashMap<节点, Vec<邻居>>）
use std::collections::{HashMap, HashSet};

pub struct Graph {
    adj: HashMap<String, Vec<String>>,     // 无权图
    // 带权图：HashMap<String, Vec<(String, u64)>> 或邻接矩阵 Vec<Vec<Option<u64>>>
}

impl Graph {
    pub fn new() -> Self { Self { adj: HashMap::new() } }

    pub fn add_edge(&mut self, from: &str, to: &str) {
        self.adj.entry(from.to_string()).or_default().push(to.to_string());
        self.adj.entry(to.to_string()).or_default().push(from.to_string()); // 无向
    }

    pub fn neighbors(&self, node: &str) -> &[String] {
        self.adj.get(node).map_or(&[], Vec::as_slice)
    }
}
```

| 表示 | 空间 | 查边 | 遍历邻居 | 适用 |
|------|------|------|----------|------|
| 邻接表 | O(V+E) | O(度) | O(度) | 稀疏图（绝大多数场景） |
| 邻接矩阵 | O(V²) | O(1) | O(V) | 稠密图、Floyd 等矩阵算法 |

> 【Java】和 Java 完全同构，唯一差别：`entry().or_default()` 比判断 contains 更惯用。

## 二、BFS：队列驱动的逐层扩散

```rust
use std::collections::VecDeque;

/// BFS：起点到各点的最短跳数（无权图最短路）
/// 模式：队列 + visited，三件套永不分离
pub fn bfs(graph: &Graph, start: &str) -> HashMap<String, usize> {
    let mut dist = HashMap::from([(start.to_string(), 0)]);   // dist 本身就是 visited
    let mut queue = VecDeque::from([start.to_string()]);

    while let Some(node) = queue.pop_front() {        // 队列：先进先出 = 层序
        let d = dist[&node];
        for next in graph.neighbors(&node) {
            if !dist.contains_key(next) {             // 未访问过
                dist.insert(next.clone(), d + 1);
                queue.push_back(next.clone());        // 访问时机：入队时标记（不是出队时！）
            }
        }
    }
    dist
}
```

**关键细节：标记时机在入队时**。出队时才标记会导致重复入队（同一节点入队多次），
是 BFS 最常见的 bug（Java 里也是同一个坑）。

### BFS 的变体族

| 变体 | 改动 | 场景 |
|------|------|------|
| 最短路径还原 | 加 `parent: HashMap<String, String>` | 导航 |
| 双向 BFS | 从两端交替扩展 | 大图加速（搜索空间平方根） |
| 多源 BFS | 初始队列放多个起点 | 「离所有仓库最近的点」 |
| 0-1 BFS | 换 `VecDeque` + `push_front`（0 权边） | 边权只有 0/1 |

## 三、DFS：栈的隐式表达（递归）

```rust
/// DFS：一条道走到黑再回头。递归即调用栈。
pub fn dfs(graph: &Graph, node: &str, visited: &mut HashSet<String>, order: &mut Vec<String>) {
    visited.insert(node.to_string());
    order.push(node.to_string());
    for next in graph.neighbors(node) {
        if !visited.contains(next) {
            dfs(graph, next, visited, order);
        }
    }
}
```

**递归 vs 显式栈**：Rust 默认主线程栈 8MB，DFS 深度超过几万层会栈溢出——
生产代码常改显式栈版本：

```rust
pub fn dfs_iter(graph: &Graph, start: &str) -> Vec<String> {
    let mut visited = HashSet::new();
    let mut order = Vec::new();
    let mut stack = vec![start.to_string()];

    while let Some(node) = stack.pop() {          // 栈：后进先出 = 深挖
        if !visited.insert(node.clone()) { continue; }   // 注意：出栈时也要查重
        order.push(node.clone());
        // 逆序 push 保持访问顺序自然（可选）
        for next in graph.neighbors(&node).iter().rev() {
            if !visited.contains(next) {
                stack.push(next.clone());
            }
        }
    }
    order
}
```

## 四、拓扑排序：Kahn 算法（BFS 版，工程首选）

**用途：依赖关系求执行顺序。** rust-im 的真实用途：SDK 初始化依赖、
配置加载顺序、（阶段 8）挂载盘的目录树构建。

```rust
/// Kahn 算法：不断摘掉「入度为 0」的节点
/// 结果：可行的执行顺序；若存在环 → 结果数量 < 节点数
pub fn topo_sort(edges: &[(&str, &str)]) -> Option<Vec<String>> {
    // edges: (from, to) 表示 from 必须在 to 之前
    let mut indegree: HashMap<&str, usize> = HashMap::new();
    let mut adj: HashMap<&str, Vec<&str>> = HashMap::new();
    let mut nodes: HashSet<&str> = HashSet::new();

    for &(from, to) in edges {
        adj.entry(from).or_default().push(to);
        *indegree.entry(to).or_insert(0) += 1;
        nodes.insert(from);
        nodes.insert(to);
    }

    // 入度初始化（没出现在 to 位置的节点入度为 0）
    let mut queue: VecDeque<&str> = nodes.iter()
        .filter(|n| !indegree.contains_key(*n))
        .copied()
        .collect();

    let mut result = Vec::with_capacity(nodes.len());
    while let Some(node) = queue.pop_front() {
        result.push(node.to_string());
        if let Some(nexts) = adj.get(node) {
            for &next in nexts {
                let d = indegree.get_mut(next).unwrap();
                *d -= 1;
                if *d == 0 {
                    queue.push_back(next);      // 依赖全部满足，可以执行了
                }
            }
        }
    }

    (result.len() == nodes.len()).then_some(result)   // 不等长 = 有环
}
```

> 【Java】完全同构于 Java 版；Rust 特有的优雅在
> `(result.len() == nodes.len()).then_some(result)`——用 Option 表达「可能有环」。
> 面试手写拓扑排序：Kahn 版（好写好讲）优先于 DFS 版。

## 五、综合实战：模块依赖分析器（30 行）

```rust
/// 输入一组模块依赖，输出加载顺序或指出循环依赖
fn main() {
    let deps = [
        ("transport", "protocol"),
        ("server", "transport"),
        ("server", "storage"),
        ("client", "transport"),
        ("sdk", "server"),
        ("sdk", "client"),
    ];
    match topo_sort(&deps) {
        Some(order) => println!("加载顺序：{order:?}"),
        None => println!("检测到循环依赖！"),
    }
    // 输出示例：["protocol", "storage", "transport", "client", "server", "sdk"]
}
```
