## 一、手写三巨头

### 快排：分区思想（面试手写频率第一）

```rust
/// Lomuto 分区版快排（最好写、最好讲）
pub fn quicksort(arr: &mut [i32]) {
    if arr.len() <= 1 { return; }
    let pivot = partition(arr);
    let (left, right) = arr.split_at_mut(pivot);    // 核心篇学过的 split_at_mut！
    quicksort(left);
    quicksort(right[pivot + 1..])                    // 分割后右段（含 pivot 排除）
}
// ↑ 注意上面写法有误示范——正确版本见下
```

```rust
/// 正确的 Lomuto 版（pivot 取末元素，返回其最终位置）
pub fn quicksort(arr: &mut [i32]) {
    if arr.len() <= 1 { return; }
    let p = lomuto_partition(arr) + 1;              // p = 左段长度（pivot 归位）
    let (left, right) = arr.split_at_mut(p);
    quicksort(left);
    quicksort(&mut right[1..]);                     // 跳过已归位的 pivot
}

fn lomuto_partition(arr: &mut [i32]) -> usize {
    let n = arr.len();
    let pivot = arr[n - 1];
    let mut i = 0;                                   // i：小于区的右边界
    for j in 0..n - 1 {
        if arr[j] < pivot {
            arr.swap(i, j);                          // 小于区扩张
            i += 1;
        }
    }
    arr.swap(i, n - 1);                              // pivot 归位
    i
}
```

复杂度账本：

| 情形 | 时间 | 触发条件 |
|------|------|----------|
| 平均 | O(n log n) | 随机数据 |
| 最坏 | O(n²) | 已排序输入 + 固定取 pivot（工程解法：**随机 pivot / 三数取中**） |
| 空间 | O(log n) | 递归栈 |
| 稳定性 | ❌ 不稳定 | swap 跨距离换位 |

> 【实战】标准库 `sort_unstable` = **pattern-defeating quicksort（pdqsort）**：
> 已排序/重复多的输入有专门模式识别（pattern defeat），跑出接近 O(n)。
> 你的手写版在已排序输入上是最坏 O(n²)，pdqsort 在同样输入上反而最快——
> 这就是「工业排序」和「教材排序」的距离，面试聊出来是强加分。

### 归并：分治 + 稳定

```rust
pub fn merge_sort(arr: &mut [i32]) {
    let n = arr.len();
    if n <= 1 { return; }
    let mid = n / 2;
    merge_sort(&mut arr[..mid]);
    merge_sort(&mut arr[mid..]);

    let mut merged = Vec::with_capacity(n);
    let (left, right) = arr.split_at(mid);           // 不需要 mut，双指针读
    let (mut i, mut j) = (0, 0);
    while i < left.len() && j < right.len() {
        if left[i] <= right[j] {                     // <= 保证稳定
            merged.push(left[i]); i += 1;
        } else {
            merged.push(right[j]); j += 1;
        }
    }
    merged.extend_from_slice(&left[i..]);
    merged.extend_from_slice(&right[j..]);
    arr.copy_from_slice(&merged);                    // 拷回原切片
}
```

稳定 O(n log n)，但要 O(n) 辅助空间——标准库 `sort`（稳定）是
**插入排序（小段）+ 归并（大段）+ 切片复用缓冲** 的混合体（TimSort 近亲）。

### 堆排序：O(1) 空间的保证

```rust
pub fn heapsort(arr: &mut [i32]) {
    let n = arr.len();
    // ① 建大顶堆（Floyd 自底向上 O(n)）
    for i in (0..n / 2).rev() {
        sift_down(arr, i, n);
    }
    // ② 反复取最大放尾部
    for end in (1..n).rev() {
        arr.swap(0, end);           // 堆顶（最大）换到已排序区
        sift_down(arr, 0, end);     // 堆大小缩为 end，重新下滤
    }
}

fn sift_down(arr: &mut [i32], i: usize, n: usize) {
    let mut i = i;
    loop {
        let (l, r) = (2 * i + 1, 2 * i + 2);
        let mut largest = i;
        if l < n && arr[l] > arr[largest] { largest = l; }
        if r < n && arr[r] > arr[largest] { largest = r; }
        if largest == i { break; }
        arr.swap(i, largest);
        i = largest;
    }
}
```

### 三巨头对比 + 库的选择

| | 快排 | 归并 | 堆排 |
|---|---|---|---|
| 平均 | O(n log n) | O(n log n) | O(n log n) |
| 最坏 | O(n²) | O(n log n) | O(n log n) |
| 空间 | O(log n) | O(n) | O(1) |
| 稳定 | ❌ | ✅ | ❌ |
| 缓存友好 | ✅✅ | ✅ | ❌（跳跃访问） |

**Rust 标准库的选择**：默认 `sort`（稳定，需要稳定时）、`sort_unstable`（pdqsort，
更快且省内存）。**日常永远用库**，手写只为面试和理解——这句话本身就是面试标准答案。

## 二、二分：三大模板（比排序更常出现在真实代码里）

二分难的不是写出来，是**写对边界**。以下三个模板覆盖 95% 场景。

### 模板一：精确查找（binary_search 的手写版）

```rust
/// 返回 Some(idx)；找不到 None
pub fn binary_search_exact(arr: &[i32], target: i32) -> Option<usize> {
    let (mut lo, mut hi) = (0, arr.len());           // [lo, hi) 左闭右开
    while lo < hi {
        let mid = lo + (hi - lo) / 2;                // 防溢出写法（Rust debug 下会 panic 溢出）
        match arr[mid].cmp(&target) {
            std::cmp::Ordering::Equal => return Some(mid),
            std::cmp::Ordering::Less => lo = mid + 1,
            std::cmp::Ordering::Greater => hi = mid,
        }
    }
    None
}
```

### 模板二：左边界（第一个 >= target 的位置）——partition_point 就是它

```rust
/// 「第一个满足谓词的位置」：lower_bound
/// 语义：返回值把数组切成 [不满足, 满足] 两半
pub fn lower_bound(arr: &[i32], target: i32) -> usize {
    let (mut lo, mut hi) = (0, arr.len());
    while lo < hi {
        let mid = lo + (hi - lo) / 2;
        if arr[mid] >= target { hi = mid; }          // 满足 → 收右界（答案可能是 mid）
        else { lo = mid + 1; }                       // 不满足 → 跳过
    }
    lo
}
// 标准库一行等价：arr.partition_point(|x| *x < target)
```

### 模板三：右边界（最后一个满足条件的位置）

```rust
/// 「最后一个 < target 的位置」= 「第一个 >= target 的位置」- 1
/// 永远可以转化成模板二！记住这一个就够
let first_ge = lower_bound(arr, target);
let last_lt = first_ge.checked_sub(1);
```

> **心法：二分只有一种模板（模板二）**。
> 精确查找 = 找到后 return；右边界 = 左边界减一。
> 所有二分题先写清楚谓词 `p(x)`，数组必然形如 `[F...F, T...T]`，
> 二分就是在找 T 区间的左端点。这就是 partition_point 的命名哲学。

### rust-im 里的真实二分

```rust
// 一致性哈希环找节点（算法篇 03 的 HashRing）
ring.partition_point(|(h, _)| *h < key_hash) % ring.len()

// 去重窗口：有序 seq 数组里找「第一个 > last_delivered 的位置」
```

## 三、基准测试入门（本系列的检验工具）

```rust
// benches/sort_bench.rs
use criterion::{criterion_group, criterion_main, Criterion};

fn bench_sorts(c: &mut Criterion) {
    let data: Vec<i32> = (0..100_000).map(|i| (i * 7 + 3) % 100_003).collect();

    let mut g = c.benchmark_group("sort_100k");
    g.bench_function("std_stable", |b| {
        b.iter_batched(|| data.clone(), |mut v| v.sort(), criterion::BatchSize::SmallInput)
    });
    g.bench_function("std_unstable", |b| {
        b.iter_batched(|| data.clone(), |mut v| v.sort_unstable(), criterion::BatchSize::SmallInput)
    });
    g.bench_function("my_merge_sort", |b| {
        b.iter_batched(|| data.clone(), |mut v| super::merge_sort(&mut v), criterion::BatchSize::SmallInput)
    });
}
criterion_group!(benches, bench_sorts);
criterion_main!(benches);
```
